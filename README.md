# 🌿 e-plantShopping

**e-plantShopping** is a modern React-based shopping cart application for an online plant nursery. It allows users to browse different categories of plants, add items to a cart, manage quantities, and simulate a smooth e-commerce shopping experience.

---

## 🚀 Features

### 🏠 Landing Page

* Clean and engaging landing page
* Button to navigate directly to the product listing page

### 🧭 Navigation Bar

* Easy navigation across:

  * Landing Page
  * Product Listing Page
  * Shopping Cart Page

---

### 🌱 Product Listing Page

* Displays a variety of plants in attractive product cards

* Each plant card includes:

  * Image
  * Name
  * Description
  * Price
  * **Add to Cart** button

* Plants are organized into at least two categories, such as:

  * 🌿 Aromatic Plants
  * 🌼 Medicinal Plants

---

### 🛒 Shopping Cart Page

* Displays all added products in the cart
* Each plant type has its own cart card showing:

  * Thumbnail image
  * Unit price
  * Total cost per plant type
  * Quantity controls:

    * ➕ Increase quantity
    * ➖ Decrease quantity
  * ❌ Delete item button

---

### 🛍️ Cart Actions

* Continue Shopping button (redirects to product listing)
* Checkout button for finalizing purchase flow

---

## 🧠 Key Functionalities

* Dynamic cart state management
* Quantity-based price calculation
* Component-based architecture using React
* Clean separation of UI sections for scalability

---

## 🛠️ Tech Stack

* React.js
* JavaScript (ES6+)
* HTML5 & CSS3
* React Router (for navigation)
* State management using React hooks

---

## 🎯 Purpose

This project demonstrates core front-end development skills including component design, state management, routing, and building a complete e-commerce UI experience using React.
